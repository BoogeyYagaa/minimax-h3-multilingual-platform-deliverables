# 本批平台操作经验与限制记录

适用范围：VideoWeb 2026-09-10，本批实际账号与文章。记录分为用户确认、公开源证据及操作故障；不当作所有账号永久通用的规则，也不虚构公开验收通过。

| 平台 | 本次证据与下次交接注意事项 |
|---|---|
| PromptZone | Markdown 必须包含文内图片占位、ALT、图注与插入位置；手动上传后替换本地路径，清除操作注释。用户确认原始描述/标签无法按原值设置。 |
| Tumblr | 用户确认编辑区无 H3；视觉字号不等于 HTML 标题级别。不要反复要求无支持的级别调整。富文本复制面应自带插图占位与完整 ALT、图注。 |
| Zenn | 独立标题栏只粘纯文本，不带 #；正文不重复 H1。用户确认标题长度限制，但具体上限未提供，不能编造。 |
| vc.ru | 六字段模板要逐行检查，不能只看文字是否齐全；两段模板本次已恢复。用户确认图片可见标题与 ALT 重复问题是编辑器局限。 |
| PromoteProject | 当前原生 Summernote 图片上传失败，不能归因到网站全面不支持或确定网络故障。用户确认标题视觉无误，语义层级和描述/标签差异为编辑器局限。正文缺图与这些局限分开。 |
| Overblog | 本次两条锚文本曾丢失 href，必须验证真实可点击链接，不只检索文字。恢复后各链接一次。H3 输出 div.ob-h3 的差异按用户确认局限保留。 |
| Paragraph | 本次公开源有三张文内图；历史用户观察与后来捕获分别保留。用户报告无 ALT 字段，不能要求不可用项；额外 cover 与描述差异尚未处理。 |
| WordPress.com | 用户质疑标题层级报告；必须检查确切文章页原始元素与选择器，不将站点壳、文章标题或视觉字号混淆。新审计确认 header h1.wp-block-site-title 与 main h2.wp-block-post-title 为不同实际元素，语义差异保留；CSS 字号不改变标签级别。 |
| Blogger | 本次单张首图为冻结例外。文章标题语义及页面 lang 可能涉及博客/模板级设置，未在收尾时擅改。 |
| Ameba Blog | 原生标签适配单独记录，公开页与本地原始标签分开，不默默宣称所有字段完全一致。 |
| LinkedIn | 发布回执与匿名访问是两件事。匿名重定向后 451 不证明文章被删除；保留验证限制。 |
| DEV Community / Qiita | 本批账号被停用，未发布；不为凑数量自动更换平台或另建账号。 |

## 工作流经验

- 可视化载荷必须包含 TAGS、SEO description、图片 ALT、图注、文件名及准确的文内插入位置。独立标题栏和正文复制边界明确。
- HTML 富文本与 Markdown 两条复制路径都需要实际占位；不能只在正文之外放图片卡。
- 用户确认字段不存在后，只关闭对应修复要求；保留实际公开结构，不宣称字段已恢复。
- 公开链接、技术复核、图片可用性、用户验收、行政收尾分开统计。
- 两个指纹浏览器按 profile/PID/kernel/CDP 端口隔离，不能停止无关 MusicMaker 工作；CU 与 CDP 在授权范围内切换。
- 语言任务保留复用；原 W/R 保持文章归属，新角色沿用 Terra/xhigh，主控模型不擅改。
- 本批未达正式公开 QA 通过的规则，仅作带来源的操作经验/限制档案，不晋升成永久平台成功发布技能规则。
